
## Convención por tarea

```
tareaNN/
├── README.md        # objetivo y contenido
├── enunciado.md     # fuente editable (Markdown) del documento entregado
├── entrega.pdf      # el PDF exacto que se sube a Avanza
├── src/             # código, si la tarea lo lleva
└── data/            # datos pequeños
```
